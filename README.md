
# Flower Image Classification

An individual AI course project developed in Google Colab using Python and TensorFlow/Keras.

The project trains a convolutional neural network (CNN) to classify five flower categories: daisy, dandelion, roses, sunflowers, and tulips.

It includes image preprocessing, model training, and evaluation using accuracy, a classification report, and a confusion matrix.

## How to Run
Open `AI_Project.ipynb` in Google Colab, upload `ImageClassificationDataset.zip`, and run the cells in order.
